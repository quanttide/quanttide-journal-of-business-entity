# 量潮科技工作日志

## 目录结构

| 目录 | 路径 | 说明 |
|------|------|------|
| default | `default/` | 无法归类到具体业务的信息（公司层面事务、跨业务思考等） |
| qtclass | `qtclass/` | 量潮课堂与实训基地日志 |
| qtcloud | `qtcloud/` | 云服务日志 |
| qtdata | `qtdata/` | 数据业务日志 |

> 已归档目录见 `data/archive/journal/`（default、qtadmin、qtacademics、qtalliance、qtbusiness、qtconsult、qtcrowd、qtopen、qtproduct、qtrecurit 等）。

## 初始化

```bash
git submodule update --init --recursive
```
